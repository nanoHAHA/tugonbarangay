# TugonBarangay

A web-based citizen response and incident management system built with Laravel, Livewire, Tailwind CSS, and Alpine.js, featuring bilingual interface support (English / Tagalog), incident reporting and tracking, digital blotter archiving, administrative tools, and system evaluation features.

## Tech Stack
* **Backend:** PHP & Laravel Framework
* **Frontend / Reactivity:** Livewire, Tailwind CSS, Alpine.js, Blade Templates
* **Build Tool:** Vite
* **Database:** SQLite / MySQL (configurable via `.env`)
